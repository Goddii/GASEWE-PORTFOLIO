Safaricom's Daraja API doesn't fail gracefully. STK Push callbacks arrive asynchronously—sometimes seconds later, sometimes never. If your server misses the callback, the customer's money is gone but your ledger shows nothing. I've wired M-Pesa into three production platforms (Vyloc, YFixIt, SokoMtaani), and every integration taught the same lesson: you need idempotent webhook handlers, cryptographic HMAC signature verification, and aggressive retry queues with exponential backoff. There is no "happy path" in African fintech—you engineer for the failure path first, or your users pay the price.

When I built The Exodus for the Jitume Hackathon, the hardest part wasn't the LLMs—it was the orchestration. Agent 1 parses raw meeting transcripts into structured briefs. Agent 2 takes that brief, cross-references internal rate cards, and generates scoped client proposals. The contract between those two agents has to be deterministic—no hallucinated JSON keys, no schema drift. That's where Pydantic strict validation became non-negotiable. Building agentic pipelines forced me to think about interface contracts, data boundaries, and failure isolation at a level that traditional CRUD applications never demand. It was the most intense systems architecture lesson I've had—and it won 1st place.

Dark-mode design is easy to get wrong. Most developers flood the canvas with neon accents until every element screams for attention and nothing has hierarchy. The principle I follow: charcoal is the stage, green is the spotlight. Emerald (#10b981) appears only where the user's eye needs to land—active states, data that matters, interactive affordances. Everything else recedes into layered grays with deliberate contrast ratios. The result is an interface that feels calm and sophisticated at rest, but comes alive the moment you interact with it. Restraint is the hardest design skill.
